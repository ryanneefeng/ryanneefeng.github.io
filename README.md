# Ryan Feng - Personal Website

A static personal and academic website written in HTML and CSS. There is no
build step, package manager, framework, or JavaScript dependency.

## Use the code

1. Extract the archive.
2. Copy the contents of this folder into your GitHub repository's website root.
3. Open `index.html` in a browser to view the site locally.

Keep the HTML files and `styles.css` together. All internal links are relative,
so the site also works beneath a repository subpath.

## Files to edit

| File | Content |
| --- | --- |
| `index.html` | Home page and brief introduction |
| `about.html` | Louisiana, swimming, gaming, lifting, and campus life |
| `mathematics.html` | Mathematical interests, Professor Raghuram, and possible future paths |
| `projects.html` | Poker equity calculator and options backtester |
| `experience.html` | Cornell, Starcycle.ai, and LSU roles |
| `education.html` | Education, coursework, honors, and certifications |
| `contact.html` | Email, GitHub, and LinkedIn |
| `styles.css` | Colors, fonts, spacing, mobile layouts, and print styling |

The header, navigation, sidebar, and footer are ordinary HTML repeated in each
page. If you change shared information, update it in all seven pages.

Navigation, contact links, and responsive styling work without JavaScript.
