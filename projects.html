Poker Hand Equity Calculator

May–July 2026

Python · Object-oriented programming · Monte Carlo simulation · SQLite

A Texas Hold’em equity calculator that combines simulation and exact enumeration. It uses 10,000-run Monte Carlo simulations before and on the flop, then switches to exact enumeration on the turn and river in heads-up play.

From equity to decisions

The decision engine uses pot odds and stack size to recommend folding, calling, raising, or going all-in. Raise sizing is capped by both a percentage of the pot and the remaining stack, with equity floors and chop-pot detection.

Game modes & implementation

  • Single-round mode for analyzing a hand.
  • Continuous mode with position-aware fold tracking, multi-street equity projection, hand-strength descriptions, and dead-card removal.
  • SQLite session logging and a 40-test pytest suite across four test modules.

Options Strategy Backtester

June 2026

Python · Statistical volatility modeling · In-sample and out-of-sample testing

A systematic backtesting framework evaluating twelve strategies across a twenty-five-stock basket over a five-year window.

Modeling & validation

The framework uses statistical volatility modeling and in-sample and out-of-sample parameter testing to evaluate strategies.

One useful part of this project was investigating an unexpected profitability pattern. I traced it to a flaw in the underlying data model and confirmed the root cause with a controlled synthetic-data test.
